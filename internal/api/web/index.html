Controlled vocabulary

  

  

  

    
    
    
  

  




  
Jobs

  
Queued and running work (process, regenerate, re-extract, ingest) — cancel any single job: queued ones leave the queue at once, running ones stop before their next step.

  

  



  
Settings

  
Applied immediately to the running server and saved to config.yaml. Server LIFECYCLE (starting/stopping bundled llama-servers) needs a rerun of ./vellum.sh — it is safe to run again anytime.

  

  

    
    
    
  

  



  
Import / Export

  
The whole library is one SQLite file: 

  
Export (backup)

  
Downloads a consistent snapshot of the library — safe to run any
    time, even while processing. A backup is a plain database file; keep it
    anywhere, restore it below.

  

  
Import (restore)

  
Replaces the live library with the chosen backup file. Jobs must
    be idle. A copy of the current library is kept next to it as
    library.db.pre-import-<timestamp> — an import is always
    recoverable.

  

    
    
  

  

  



  
Rename category

  
Renames the shelf everywhere it is used and moves its whole
    subtree with it (e.g. machine-learning →
    computer-science/machine-learning). Slashes nest
    subcategories; renaming onto an existing shelf merges the two.
